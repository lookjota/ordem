# New consumer guide

1. Crie o diretório do app consumidor.
2. Defina branding e um tema estrutural que forneça os tokens visuais.
3. Registre extensions de sections quando a composição exigir uma section nova.
4. Crie conteúdo e assets do app fora de `src/engine`.
5. Escreva `PageDefinition` tipadas.
6. Configure as rotas do consumidor.
7. Gere metadata e structured data do próprio domínio.
8. Forneça o shell/navegação e os adapters de integração.
9. Execute typecheck, lint, testes, build e `npm run audit:engine`.

O core não precisa ser alterado para criar páginas com outra identidade ou outro domínio.
